# Windows版の起動方法

`PortableMarkdownEditor-win-x64.zip` は、ビルド済みのWindows x64版です。

ZIPを展開し、`PortableMarkdownEditor` フォルダ内の `PortableMarkdownEditor.exe` をダブルクリックしてください。

Visual Studio、Visual Studio Installer、MSBuildは不要です。

`BuildPortableWindows.cmd` は実行しないでください。

このファイルは開発者がソースから再ビルドするときだけ使います。

アプリ本体のインストール、管理者権限、ユーザー登録、ログインは不要です。

Windows 11には通常、必要な.NET FrameworkとWebView2 Runtimeが含まれています。

起動しない場合は、表示されたエラーメッセージを確認してください。

ZIPのSHA-256は `SHA256SUMS.txt` に記載しています。
